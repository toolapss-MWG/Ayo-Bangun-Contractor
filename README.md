# AyoBangun Contractor v1.0

Construction ERP Application

Features:
- Project Management
- Material POS
- Inventory Automation
- Workforce Attendance
- Payroll
- Progress Monitoring
- RAB & Finance
- Procurement
- Reporting
- WhatsApp Notification
- Digital Project Archive

Stack:
React + Vite
Firebase
Capacitor Android

Setup:
1. npm install
2. Configure Firebase
3. npm run build
4. firebase deploy
